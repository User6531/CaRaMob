## 🔧 Як використовувати

### В компонентах
```typescript
import { useTheme } from '../hooks/useTheme';
import { globalStyles } from '../styles/globalStyles';

const MyComponent = () => {
  const theme = useTheme();
  
  return (
    <View style={[globalStyles.container, globalStyles.pageBackground]}>
      <Text style={globalStyles.textPrimary}>Текст</Text>
    </View>
  );
};
```

### Швидка зміна кольорів
1. Відкрийте `src/styles/theme.ts`
2. Замініть `darkTheme` на одну з тем з `themeVariants.ts`
3. Оновіть `cssVariables` відповідно
4. Перезапустіть додаток
